# Changelog

Release history for DevPassDiscordRelay.

## [0.1.0] - 2026-09-30

Initial release delivering the six core milestones.

### Milestone 1: Terminal Session Mirroring

- Tails SQLite transcripts from `opencode.db` in read-only WAL mode.
- Pairs newly discovered session rows with pending markers generated by `dpmux`.
- Creates dedicated Discord threads for each mirrored session.
- Streams assistant responses with rate-limited edits under five edits per five seconds.
- Chunks messages exceeding character limits at natural boundaries.
- Renders in-place tool call status embeds and completion summaries.

### Milestone 2: Live Pane Injection

- Injects replies from Discord threads into active tmux panes using `tmux send-keys`.
- Verifies pane readiness against the `Ask anything...` signature before keystroke delivery.
- Enforces single-user authorization against `DISCORD_USER_ID`; the relay refuses to start when it is unset or empty.
- Drops unauthorized user and bot dispatches at the gateway event boundary.
- Supports thread title renaming from Discord.
- Downloads attached images to local staging directories and appends paths to prompts.

### Milestone 3: Discord Session Spawning

- Launches new sessions via `dpmux` upon receiving root channel messages outside threads.
- Binds new sessions using creation timestamp order and pending marker validation.
- Routes the initiating Discord message as the initial prompt to the spawned agent.

### Milestone 4: Dead Session Resumption and Refusal Handling

- Resumes terminated sessions with `--session <id>` when receiving replies in existing threads.
- Verifies injection echo in SQLite within thirty seconds to detect swallowed keystrokes.
- Suppresses duplicate prompt echoes in Discord threads after retry dispatches.
- Detects resume refusals through dual signals of pane refusal text and foreign database rows.
- Terminates refused panes by sending `SIGTERM` to the pane process group.
- Presents numbered candidate lists when requested session identifiers match multiple targets.

### Milestone 5: Interactive Approvals and Menus

- Detects terminal permission prompts from pane content using `capture-pane`.
- Renders interactive Approve and Deny component buttons in Discord threads.
- Executes version-pinned keystroke sequences upon button interactions.
- Automatically denies unanswered permission prompts upon timeout expiry.
- Renders selection menus for interactive option prompts.

### Milestone 6: Lifecycle Survival and Packaging

- Wraps tmux server birth inside `systemd-run --scope` to isolate processes from the daemon unit.
- Preserves active tmux windows across relay restarts and daemon upgrades.
- Sweeps stale inactive records in `sessions.json` based on configurable retention limits.
- Delivers idempotent `install.sh` installer configuring local binaries and systemd user services.
- Optional telemetry: off unless `TELEMETRY_URL` is set; when set, at most one POST per UTC day from a running relay (not only at startup) carrying `sha256(username)[:12]` and the version. The digest is pseudonymous, not anonymous.
